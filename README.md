## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Session Log** | Track RX 11 repair sessions with source audio and issue notes |
| **Module Config** | Document settings for Spectral Repair, De-noise and De-click |
| **Repair Presets** | Save named RX processing configurations per audio source type |
| **Dialogue Workflow** | Track dialogue repair workflows with module chain documentation |
